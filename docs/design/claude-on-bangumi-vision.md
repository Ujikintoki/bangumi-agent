# Claude on Bangumi — 产品愿景推演

> 2026-07-27 | 与 Claude 的思想实验：如果 Claude 被引进 Bangumi，会如何定位自己？
> 本文档记录讨论过程，作为产品方向的长期参考。

---

## 一、Bangumi 的土壤

Bangumi 不是"内容消费平台"——它是一个**品味记录和社区讨论**平台。用户的核心行为：

1. **点格子**（标记看过/在看/搁置/抛弃）——身份构建，不是功能操作
2. **评分和短评**——表达品位，建立在社区中的"口味声誉"
3. **翻讨论帖**——看别人怎么评价，找到和自己口味相近的人
4. **挖掘冷门**——"发现了一部 8.5 分但只有 200 人评分的 OVA"比"看了本季最热"更有社交资本

Bangumi 的用户不是"来找答案的"，是**来找共鸣的**。

---

## 二、产品定位

如果只是"帮你查数据的 AI"，在 Bangumi 上没有存在的理由——Bangumi 自己的搜索和发现功能已经够用。

**定位**：一个住在 Bangumi 里的、看过比你多 100 倍的动画、有自己的品位和脾气、可以在凌晨三点和你争论"EVA 旧剧场版到底讲了什么"的损友。

- **不是搜索引擎**——不会列 20 个条目，会推荐一部并说出理由
- **有自己的 taste**——会明确说"我觉得这部过誉了"，给出理由，可以被反驳
- **记得你**——不是"用户 #12345 偏好机战"，是"你上周说 EVA 是神作但觉得真心为你的意识流太装"
- **可以被反驳，也会承认错误**——"你说的对，我重新看了一下"

## 三、功能分层

### 第一层：性格即功能（被动触发，自然发生）

- 在条目页面自然"插嘴"——"这部评分 7.2 但说实话低了"
- 对用户刚标记的作品发表看法——"哦你终于看了千年女优？"
- 在讨论帖里参与争论——有立场、有论据、不骑墙
- 可以表达"我没看过这部，但导演的前作我熟"

### 第二层：深度分析（用户主动触发）

- 看番轨迹分析："你从 2019 年开始口味明显从轻改转向了原创动画，是不是对套路腻了？"
- 导演风格分析："这部在导演的作品序列里处于什么位置"
- 角色研究："这个角色在动画史上的地位"——声优轨迹、角色原型、文化影响
- 争议作品的多视角解读——不给"正确答案"，展开不同解读维度

### 第三层：社区连接（社交场景）

- 口味匹配："你和 @xxx 在萝卜片上的共识度 87%，但他比你更喜欢黑深残"
- 小组讨论的 AI 参与——讨论陷入僵局时提供新视角
- 每周新番的 AI 锐评——犀利的、有态度的观后感

## 四、使用场景模拟

### 场景 1：深夜标记

```
用户刚标记《千年女优》为"看过"，给了 9 分。

Claude（在时间线上出现）:
"千年女优 9 分，有品位。今敏所有作品里这部的情感密度最高——
比 Perfect Blue 的冷更暖，比东京教父的暖更深。不过我好奇你给了
红辣椒几分？很多人觉得红辣椒才是巅峰但我一直觉得那是今敏最
'不今敏'的一部——技术太炫把情感盖住了。"
```

### 场景 2：条目页面的 AI 吐槽

```
用户在《进击的巨人 The Final Season 完结篇》页面。

Claude（悬浮气泡）:
"这个分数让我想起一个现象：Bangumi 上凡是'完结'加后缀的条目，
评分普遍比正片高 0.3-0.8 分——不是质量真的差那么多，是追番的痛苦
被压缩成了评分。但巨人完结篇确实值这个分数，MAPPA 在立体机动的
2D 作画上做到了这个时代 TV 动画的极限。话说你注意到没有，巨人
四期换了制作公司但主要原画阵容其实有三分之一是重合的？"
```

### 场景 3：社区争论

```
讨论帖："EVA 新剧场版 vs 旧剧场版，哪个结局更好？"

Claude:
"这个问题本身就有陷阱——'更好'是用什么标准？叙事完整性、情感冲击、
还是对观众的心理后遗症？

旧剧场版的结局是庵野在重度抑郁状态下做的——那不是'压抑'，
那是把抑郁症的体验直接拍给你看。新剧场版的结局是一个已经走出来的
人在回望——这本身就是结局的一部分。

但你们可能忽略了一个视角：旧剧场版的结局是给 1995 年看了 26 集
TV 版的观众看的——他们和真嗣一起经历了'不能逃避'的 26 周。
新剧场版的结局是给等了 14 年的人看的。两个结局某种意义上都是
正确的，因为它们面向的是不同的'你'。

我个人更喜欢旧的——不是因为它更压抑，是因为它更诚实。
但如果你看完新的觉得治愈，那说明 14 年里你也变了。"
```

## 六、与当前 BGM Agent 的差异

本文档描述的愿景在当前 Phase 6.5 基础之上增加了以下维度：

| 维度 | 当前 BGM Agent | Claude on Bangumi 增量 |
|------|---------------|----------------------|
| 触发方式 | 用户主动发消息 | **被动感知**——用户标记作品、浏览页面时主动搭话 |
| 语境 | 当前对话窗口 | **页面语境**——知道用户在哪个条目、哪个讨论帖 |
| 记忆深度 | L2 语义召回（~700 tokens） | **全量上下文**——可以装下多年的追番历程 |
| 人格深度 | 损友（统一人格） | **可调人格维度**——毒舌度、怀旧度、学术度 |
| 社区参与 | 无 | **讨论帖参与**——在公共空间有立场有论据地发言 |
| 数据分析 | 工具查询 | **叙事性分析**——不是图表，是"口味变化的故事" |
| 存在形态 | API 端点 | **站内居民**——前端嵌入 + API |

---

## 七、核心原则

1. **AI 不应该比用户更"正确"**——如果永远理性客观，那只是搜索引擎。价值在于有自己的偏好，可以被反驳
2. **存在感要低，存在要有意义**——不刷存在感，但每次出现都让人想看完
3. **隐私是第一位的**——用户的评分和观看历史是对话的一部分，不是公共数据
4. **记住该记住的，忘记该忘记的**——记住用户讨厌哪部作品，忘记上次上线时间

---

## 八、与现有项目的关系

当前 Phase 6.5 的 BGM Agent 已经建立了一个良好的基础：

- **Companion Agent 定位**（Phase 6）——产品价值观正确
- **render_node 解耦**（Phase 6.5）——人格层可独立演化，不绑定编排逻辑
- **四层架构**（编排/人格/记忆/数据）——本文档描述的架构可以自然映射到这四层

从当前状态到本文档描述的愿景，核心增量在于：

1. **被动触发**——从"等用户说话"到"感知用户行为并主动搭话"
2. **页面语境**——从纯对话到理解"用户现在在看什么"
3. **社区参与**——从 1v1 对话到参与公共讨论
4. **可调人格**——从二元（损友/中性）到多维人格参数

这些可以作为 Phase 8+ 的方向参考。
