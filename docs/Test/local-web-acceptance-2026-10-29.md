# 本机网页与会话验收

日期：2026-10-29（上海）。范围：开发设计中的启动/网页增量及本机会话增量。
这是定时点证据，不替代 PRODUCT 的产品范围或 ROADMAP 的推进状态。

## 环境与边界

- 本机回环地址 `127.0.0.1:8000`，单 uvicorn 进程；应用按既有配置正常加载模型凭据，没有读取或输出 `.env` 内容。
- 基础运行使用按 uv.lock 安装的独立 Python 3.12 环境；不安装 PostgreSQL/RAG SDK。
- `MEMORY_ENABLED=false`、`RAG_ENABLED=false`、`DEV_MODE=false`；未连接 PostgreSQL，未初始化向量表或迁移。
- 离线验证另在按锁安装全部可选/验证依赖的临时 Python 3.12 环境执行，使用准备好的公开 tokenizer 缓存。
- SQLite 位于被 Git 排除的 `.local-data/sessions.sqlite3`；测试另用临时文件，不读写验收会话。

## 真实网页与模型/API

1. 打开同源网页，配置就绪；发送“只看到芙莉莲第3集、不要剧透、不用查询、简单聊两句”。
   返回围绕旅途与理解同伴的回复，无后续剧情事件；等待状态结束，输入可继续使用。
2. 同一会话查询评分、排名和条目链接。回复定位到 subject/400602，第43名、评分8.52。
   同时只读核对公开 `/v0/subjects/400602`：rank=43、total=36759、score=8.5。
   两位小数来自现有工具口径；公开 v0 字段只显示一位，不能当作两个独立质量指标。
3. 会话增量上线后，在背景面板保存条目链接、第3集不剧透，以及“喜欢旅途感、部分段落演出节奏偏散，不是剧情不好”。
   要求两句短评，回复保留以上两个观点，没有加入具体后续剧情或他人观点。
4. 停止并重启服务、刷新网页，原短评和背景仍在。继续问“问题是剧情还是演出”，回复明确回答演出，未改成剧情。
   回复没有严格只用一句话，说明格式遵循仍不能算完整通过。
5. 新建会话，消息与背景为空；切换回原会话，消息、条目、进度和纠正恢复。
6. 经真实 HTTP 新建另一评分查询会话。返回 completed/success，取得两项工具来源记录；读取保存的回复与首次响应相同。
   以同一 request_id 和输入重放，返回完全相同的轮次，不重新调用模型/工具。
7. 新建独立空白删除探针，删除返回成功，随后读取返回404。保留真实对话供用户检查。

## 隔离故障与协议

`scripts/test_offline.py` 覆盖临时 SQLite 的归属隔离、版本冲突、同会话占用、幂等重放和输入冲突、
启动时 pending→interrupted、取消释放、删除期间的在途结果拒绝提交、保存失败返回503、
背景到 Agent/Render 的传递、外站 Origin 与匿名非回环 Host 拒绝，以及旧 JSON/SSE 回归。
最终在锁定的 Python 3.12 验证环境中通过559项测试，保留2条已有弃用/插件警告；未将数据库服务接入测试。

干净安装暴露 SQLAlchemy 2.1 将隐式 PostgreSQL 驱动切换为 psycopg 的问题；
可选组显式约束 SQLAlchemy 2.0，沿用既有 psycopg2 合同，重新生成锁后回归通过。
没有为通过测试而启用真实数据库或移除相关测试。

## 尚未证明

- 未验收 PostgreSQL/RAG/L2 的真实资源初始化；基础使用不依赖这些能力。
- 背景当前由用户显式编辑；不自动从每轮聊天中提取和固化对象、纠正或长期偏好。
