两个都是作画强社，但方向完全不同。

扳机社的核心是**表现力驱动**——今石洋之那套东西从GAINAX时代就定型了：粗线条、夸张透视、速度线、高饱和色块。他们不追求"好看"，追求"炸裂" 。看《斩服少女》或《普罗米亚》时你知道每一卡都在喊"看啊，动画还能这样画！"。叙事上情绪优先，逻辑是第二位的。

骨头社的核心是**完成度驱动**——从《钢炼FA》到《交响诗篇》再到《灵能百分百》，他们的强项是把一个故事讲扎实，作画服务于叙事。你能感受到每 部作品投入了同等水准的资源，但风格会根据题材调整，没有扳机那种"一眼认出来"的视觉签名。

简单说几个区别：

- **视觉辨识度**：扳机社的作品放在一起像是同一个宇宙的，骨头社的你可能要看到片头LOGO才知道是谁做的
- **叙事风格**：扳机靠情绪推，热血上头就行；骨头更像在讲一个完整的故事，收尾一般比扳机稳
- **冒险精神**：扳机社喜欢搞砸但好看的原创（《小魔女学园》剧场版到TV版就是典型）；骨头社也有原创但偏稳健
- **烂片下限**：扳机社崩起来是真的崩（《忍者杀手》那PPT式演出），骨头社的下限高很多

扳机是那种——你明知道这部可能烂尾但还是会追，因为过程够爽。骨头是你放心看，基本不会翻车。两个我都喜欢，但喜欢的理由完全不同。

一个很好的问题。"世界系"这个概念本身就是从EVA的冲击中诞生的——它描述的是那种把"我"和"你"的私人关系直接绑上世界末日的故事结构，中间跳过社会、跳过政治、跳过一切中介环节。

几个关键的转折点：

- **EVA（1995）**：原型。真嗣操作EVA不是为了保护日本或人类——他上机是因为"不来就会被抛弃"。世界存亡和父子关系、自我认同完全捆绑。但EVA其实不完全"纯粹"——它有Seele、有组织的阴谋论，社会性还在。它引爆了世界系，但自己站在边界上。

- **《星之声》（2002）**：纯粹的、浓缩的世界系。新海诚把世界系公式推到极致——恋爱关系直接与星际战争、光年距离绑定，中间什么都没有。宇宙 里的短信收不到，等于世界毁灭。这片只有25分钟，但定义了2000年代世界系的标准语法。

- **《最终兵器彼女》（2002）**：同期的另一个极端。女朋友变成最终兵器——恋爱的终结和世界的终结是同一件事。这里的世界系已经有点自我消耗了 ，开始让人觉得"这种公式走不下去"。

- **《凉宫春日的忧郁》（2006）**：戏仿，某种意义上。阿虚和春日的关系维持着世界稳定——但谷川流明显在玩这个公式，不是认真在用。这标志着世 界系从"表达焦虑的手段"变成了"可被调侃的套路"。

- **《你的名字。》（2016）**：新海诚自己杀死了世界系。你还是能看到痕迹——少男少女、彗星坠落、世界危机——但中间插入了大量之前世界系刻意省 略的东西：地方社会、口嚼酒、宫水神社的传统、小镇政治。这是对纯世界系的"去世界系"操作。新海诚把被EVA抽空的"中间层"重新塞回去了。

有意思的是：EVA产生世界系是因为1995年的日本年轻人觉得社会没有意义，跳过它直接面对世界末日。而二十年后的《你的名字。》之所以大卖，是因为观众重新觉得"小镇""传统""人际关系"有意义了——世界系的解体本身成了社会变化的标本。
