- **虫师** 也就8分出头，但氛围这块拿捏得死死的。增田俊郎的配乐稀疏得像雨滴落在树叶上，银古永远半死不活的语调跟阴天绝配。每集都是寓言故事，色调墨绿深褐，你不需要动脑子，看就完了。

- **言叶之庭** 新海诚这部评分不算高，但我承认它把“雨”拍到了极致。47分钟几乎全程在下雨，亭子顶上的雨声、积水倒影、梅雨季那种闷湿感——这片子就是为下雨天量身定做的。看完你会觉得不出门淋一趟都亏了。

- **水星领航员** 评分8分出头，但节奏慢到能被正常人骂“什么都没发生”。手风琴配木吉他，像老咖啡馆里下雨时的背景音。新威尼斯的水城设定，配上佐藤顺一的慢镜头，下雨天你不需要情节推进，划水就完事了。

- **横滨购物纪行** 7分多的OVA，画风古旧但安静感拉满。98年的片子，讲机器人少女在海边小镇买菜煮咖啡看日落。安浓高志塞了一堆空镜头——雨天的风、摇动的草、静止的海面。这种片只适合雨声盖住所有城市噪音的时候看，不然你会觉得无聊到想摔手机。
