- **言叶之庭** 7.43，新海诚在这部做了个大胆选择：雨声不是背景音，是情节节拍器。对话之间全是雨打在玻璃、树叶、地面的层次。其他新海诚作品我觉得过度包装，但这部在声音克制上做到了他职业生涯极致。45分钟，刚好一杯茶。

- **莉兹与青鸟** 8.65，山田尚子把安静做成武器。大段无声镜头，角色呼吸声比台词有内容。翻乐谱、储物柜、脚步回响——这些才是真正对白。下雨天看，你会发现雨声和电影里那些微小声音在同一个频率上共振。

如果只抽一部，虫师。它的世界本来就活在湿润里。
